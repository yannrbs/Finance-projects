# 02 · Black-Scholes Greeks

Computes the Greeks of a European option (with a continuous dividend yield) along a simulated path
of the underlying, to see how they evolve as time passes and as the spot moves relative to the strike.

| Greek | Measures sensitivity to |
|-------|-------------------------|
| Delta (Δ) | Underlying price |
| Gamma (Γ) | Change in Delta |
| Theta (Θ) | Passage of time |
| Vega (ν) | Volatility |
| Rho (ρ) | Risk-free rate |
